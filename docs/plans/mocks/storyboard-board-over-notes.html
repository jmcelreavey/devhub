Open questions: (1) do cards without a note get one auto-created, or stay as evidence-only cards in Unsorted? (2) screenshot source priority: Jev capture > manual > preview. (3) keep evidence cards as a secondary "Evidence" tab inside the note drawer.
Decisions (answers to the open questions above; implemented in dashboard/lib/storyboard/notes-board.ts)
  1. Cards without a note show as task-only cards built from the task record, with a one-click Create note that scaffolds the note through the existing task-note path. Nothing is created automatically; evidence with no task is dropped.
  2. Screenshot priority: newest Jev QA capture (after beats before), then the newest image in the note's Screenshots section, then none. No preview scraping.
  3. No separate Evidence tab. Clicking a card opens the task note; runs and QA links (bugs, before/after video, receipt) live on the card.
Also decided: columns are the note status (todo, planning, in-progress, needs-you, blocked, draft-pr, ready-for-review, done), not the stage front-matter this mock first showed. Moving a card means changing the status with the same set_status the note uses. Done shows the last 14 days by default.
